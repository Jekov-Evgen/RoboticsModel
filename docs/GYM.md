# Интерфейс Gymnasium

`robotics_model.envs` оборачивает `World` в окружение [Gymnasium](https://gymnasium.farama.org) — стандартный интерфейс для обучения с подкреплением. Физика детерминированна, случайность идёт только из `np_random`, который сеется через `reset(seed=...)`: одинаковые seed и действия дают побитово одинаковые эпизоды.

```sh
pip install -e ".[gym]"          # gymnasium
python -m pytest python/tests/test_envs.py
```

```python
import gymnasium as gym
import robotics_model.envs       # регистрирует идентификаторы

env = gym.make("RoboticsModel/ArmReach-v0")
obs, info = env.reset(seed=0)
for _ in range(200):
    obs, reward, terminated, truncated, info = env.step(env.action_space.sample())
```

## `RoboticsModel/ArmReach-v0`

Трёхосевой манипулятор из `examples/manipulator_3dof.robot` должен подвести инструмент к случайной точке.

| | |
|---|---|
| **Действие** | `Box(-1, 1, (3,))` — приращение целевых углов суставов (yaw, плечо, локоть), умноженное на `action_scale` = 0,08 рад за шаг. Целевые углы отрабатывают PID-регуляторы суставов, поэтому гравитация компенсируется внутри движка |
| **Наблюдение** | `Box(15,)`: углы (3), скорости суставов (3), положение инструмента (3), цель (3), цель − инструмент (3) |
| **Награда** | минус расстояние от инструмента до цели (м) |
| **Цели** | положения инструмента при случайных достижимых конфигурациях суставов, поэтому любая цель достижима |
| **Шаг** | 8 физических шагов (1/240 с) = 30 Гц; эпизод — 200 шагов (усечение, `truncated`) |
| **`info`** | `distance`, `is_success` (расстояние < 5 см), `time` |

Прямую цель можно задать через `env.reset(options={"goal": [x, y, z]})`.

Рендера у окружения нет (`render_mode=None`): визуализировать мир умеет редактор macOS.

## Эталон и пример обучения

В `robotics_model.envs.arm` есть аналитическая прямая и обратная кинематика этого манипулятора (`tool_position`, `inverse_kinematics`). Они используются, чтобы:

- проверить в тестах, что аналитика совпадает с положением инструмента в симуляции (< 2 мм);
- построить «оракул» — политику, которая идёт к решению ОЗК: она достигает цели в 9 из 10 тестовых эпизодов (среднее расстояние в конце 0,08 м), а случайная политика — нет.

[`python/examples/train_reach_es.py`](../python/examples/train_reach_es.py) обучает маленькую нейросетевую политику (15→32→3, 611 параметров) эволюционной стратегией на чистом `numpy`, без RL-библиотек:

```text
reference: standing still 1.646 m, IK oracle 0.077 m (mean final distance)
gen   0  validation distance 1.834 m
gen  20  validation distance 0.791 m
gen  40  validation distance 0.410 m   (64 s на M2)
```

За минуту политика сокращает расстояние с 1,83 м до 0,41 м, но ещё не сошлась; это демонстрация, что окружение обучаемо, а не готовая обученная модель. Для серьёзного обучения подойдёт любая библиотека, работающая с Gymnasium (Stable-Baselines3, CleanRL и т. п.).

## Как сделать своё окружение

Унаследуйтесь от `RoboticsEnv`, создайте мир в `_make_world`, задайте `action_space` и `observation_space` и реализуйте `_observe`, `_apply_action`, `_reward` и при необходимости `_reset_episode` (там берутся случайные цели из `self.np_random`). Базовый класс сам выполняет `frame_skip` физических шагов, обрезает действие и проверяет его форму.
